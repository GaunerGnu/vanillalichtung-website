# VanillaLichtung-Website – vollständiges Austauschpaket

Dieses Paket enthält die überarbeitete Website für GitHub Pages.

- Website: `https://www.vanillalichtung.de`
- Minecraft-Server: `VanillaLichtung.de`
- Kontakt: `vanillalichtung@gmail.com`
- Hosting der Website: GitHub Pages

## Stand dieses Updates

- sachlicheres, reduziertes Design
- deutlich weniger verträumte Texte
- 30 Claim-Chunks zum Start
- +1 Claim-Chunk je 90 Minuten Spielzeit
- End-Öffnung: Samstag, 05.09.2026 um 18:00 Uhr
- bis zu 32 Chunks Sichtweite
- Freischaltung über das bestehende Google-Formular
- Discord-, Vote- und Serverstatus-Funktionen bleiben erhalten
- responsive Darstellung für Desktop und Mobilgeräte
- Kontakt-, Datenschutz- und 404-Seite im gleichen Design

## Website aktualisieren

1. ZIP-Datei vollständig entpacken.
2. Im GitHub-Repository zu **Code** wechseln.
3. **Add file → Upload files** öffnen.
4. Den Inhalt des entpackten Ordners hochladen. `index.html` muss direkt auf der obersten Ebene des Repositorys liegen.
5. Vorhandene Dateien bei GitHub ersetzen lassen.
6. Als Commit-Nachricht z. B. `Website neu gestaltet` eintragen.
7. **Commit changes** anklicken.
8. GitHub Pages veröffentlicht den neuen Stand normalerweise nach kurzer Zeit automatisch.

## Wichtig zur Domain

Die bestehende `CNAME`-Datei ist bereits enthalten und zeigt auf `www.vanillalichtung.de`. Für dieses Website-Update müssen bei STRATO, DNS, SRV-Record, Minecraft-Port oder Server-IP keine Änderungen vorgenommen werden.

- `www.vanillalichtung.de` = Website
- `VanillaLichtung.de` = Minecraft-Serveradresse

## Sicherheit

Keine Minecraft-Serverdateien, Passwörter, Tokens, Backups, Logs, private Formulardaten oder Plugin-Konfigurationen in das öffentliche GitHub-Repository hochladen.
